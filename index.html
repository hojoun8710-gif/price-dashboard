데이터는 비공개 저장소에 있습니다. 이 기기에서 한 번만 연결하면 됩니다.

토큰 만드는 법
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → 비공개 데이터 저장소 하나만 선택
  3. Permissions → Repository permissions → Contents: Read and write (구매 결정 저장에 필요)
  4. 만들어진 토큰을 위 칸에 붙여 넣기. 토큰은 이 기기에만 저장됩니다.
